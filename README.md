# Stopwatch Web App

A modern and responsive stopwatch built using HTML, CSS, and JavaScript.  
This project allows users to start, pause, and reset the timer with a clean glassmorphism UI design.

---

## Features

- Start the stopwatch
- Pause the timer
- Reset the stopwatch
- Real-time milliseconds tracking
- Responsive modern UI
- Smooth button hover effects

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
